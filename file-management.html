What are Files and Folders?

Understanding Files and Folders

Files can be stored in folders. Folders can be stored within other folders and these are referred to as sub-folders. This creates a hierarchical structure similar to a filing cabinet.

File Names and Extensions

File names are made up of two parts: the document name and the file extension. The document name can be up to 255 characters long, while the file extension is determined by the application used to create the file.

Why File Extensions Matter

  • The operating system uses extensions to know which program to open the file with
  • Changing an extension does NOT change the file type (it just confuses the computer)
  • Windows hides extensions by default - you can enable them in Folder Options
  • Some extensions can contain harmful code (.exe, .scr, .vbs) - be careful with unknown files

Storage Media

Files and folders can be stored on various storage media. Different storage media have different characteristics in terms of capacity, speed, portability, and durability.

Memory Card (SD/microSD) 1GB - 1TB Small, portable, used in phones/cameras Easy to lose, can be fragile

Cloud Storage 5GB - Unlimited (paid) Access from anywhere, automatic backup, sharing Requires internet, monthly fees for large storage

Folder Naming Best Practices

  • Use descriptive names (e.g., "Math Homework" not "Stuff")
  • Use consistent naming conventions (e.g., "YYYY-MM-DD_ProjectName")
  • Avoid special characters: \ / : * ? " < > |
  • Use underscores or hyphens instead of spaces (optional)
  • Keep names reasonably short but meaningful

Pro Tips for File Management

  • Undo (Ctrl+Z) can reverse most file operations (delete, rename, move)
  • Drag and drop moves files on the same drive, copies to different drives
  • Use Ctrl while dragging to force a copy
  • Use Shift while dragging to force a move
  • Press Alt while dragging to create a shortcut

The Recycle Bin

What is the Recycle Bin?

The Recycle Bin is a temporary storage area for deleted files. When you delete a file, it is moved to the Recycle Bin, not permanently erased. This gives you a chance to recover files deleted by mistake.

Working with the Recycle Bin

:Open Recycle Bin → Right-click file → Restore:Open Recycle Bin → Restore all items (in toolbar):Open Recycle Bin → Right-click file → Delete:Right-click Recycle Bin icon → Empty Recycle Bin:Shift + Delete (deletes permanently without sending to Recycle Bin):Right-click Recycle Bin → Properties

Important Notes

  • Files deleted from network drives or USB drives go directly to permanent deletion (no Recycle Bin)
  • Files larger than the Recycle Bin's capacity are permanently deleted
  • The Recycle Bin has a maximum size (default is about 5-10% of your drive)
  • Once you empty the Recycle Bin, files cannot be easily recovered (requires special software)
  • You can change Recycle Bin properties (size, delete confirmation) by right-clicking the icon

Storage Capacity and Data Units

Understanding Data Units

In a computer system, data is represented using the binary system - combinations of binary digits (bits). There are only two binary digits: 0 and 1.

UnitAbbreviationSize in BytesExample
Bitb1/8 byteSingle 0 or 1
ByteB8 bitsOne character (e.g., "A")
KilobyteKB1,024 bytesAbout half a page of text
MegabyteMB1,024 KBA small photo (1-5 MB)
GigabyteGB1,024 MBA full-length movie (~1-2 GB)
TerabyteTB1,024 GB500 hours of video
PetabytePB1,024 TBLarge data centers

Converting Between Units

  • To convert from Bytes to KB: Divide by 1,024
  • To convert from KB to MB: Divide by 1,024
  • To convert from MB to GB: Divide by 1,024
  • To convert from GB to TB: Divide by 1,024
  • To convert to larger units, multiply (KB × 1,024 = Bytes)

Important Note

Many hard drive manufacturers use the decimal system (1 KB = 1,000 bytes) while computers use binary (1 KB = 1,024 bytes). This is why a "1 TB" drive might show as only 931 GB in your computer.

Example Conversions

4,096 MB to GB4,096 ÷ 1,0244 GB

Search Operators and Filters

  • name: - Search by filename (e.g., name:report)
  • type: - Search by file type (e.g., type:docx, type:pdf, type:jpg)
  • size: - Search by file size (e.g., size:>1MB, size:<100KB)
  • date: - Search by date modified (e.g., date:today, date:last week)
  • Wildcards: * (any characters) and ? (single character)
