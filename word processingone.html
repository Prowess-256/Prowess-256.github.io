Features of a Word Processor

What is Word Processing?

Word processing is a very important skill for computer literacy. Once you learn word processing, you will be in position to use word processing software (e.g. MS Word) appropriately to create, edit and print documents. Microsoft Office Word is one of the most commonly used word processing software.

Word Processor Interface

A word processor has numerous features whose uses you need to understand. The image below shows a typical word processor window with key features:

Office Button/File Menu

Access to Save, Open, Print, and other file operations

Home Tab

Basic formatting tools: font, paragraph, styles, editing

Insert Tab

Insert pages, tables, illustrations, links, headers/footers

Page Layout Tab

Page setup, themes, page background, paragraph spacing

References Tab

Table of contents, footnotes, citations, bibliography

Mailings Tab

Mail merge, envelopes, labels for bulk mailing

Review Tab

Spelling & grammar, proofing, comments, tracking changes

View Tab

Document views, zoom, window arrangements, macros

Customizing Word Processing Environment

Before you begin creating documents, ensure that you have set up your Word environment and become familiar with key tasks such as minimizing and maximizing the Ribbon, configuring the Quick Access toolbar, using the ruler, word counting and zooming tools.

3

Right-click anywhere in the main menu and select "Minimize the Ribbon" to toggle the Ribbon on and off.

4

Customize Taskbar

Saving Documents

Importance of Saving

Saving is a process of storing a document in a certain location or creating a file. This can be done on a newly created document or on an already existing document. Saving is normally in two categories: Save and Save As.

Save vs Save As

Operation When to Use Result
Save First time saving or updating existing file Saves changes to current file location with same name
Save As Creating copy, changing location, or changing file type Creates new file with different name, location, or format
3

1

Open MS Word

Start the Word processing program.

2

Select Save/Save As

Select Office Button → Save or Save As (or File → Save/Save As in newer versions).

3

Choose Location

Select Desktop or My Documents as the location to save in.

4

Name the File

Give the file a name like "NCDC" and click Save.

Important Tip

Save your file immediately after creating it to prevent the possibility of losing it later due to power failure. Use Ctrl+S frequently to save your work as you go.

Working with Text

Basic Text Operations

Working with text involves selecting, inserting, deleting, copying, and pasting text. These fundamental skills are essential for creating and editing documents effectively.

Text Selection Methods

To Select Method Keyboard Shortcut
Single word Double-click the word Double-click
Line of text Click in left margin next to line Triple-click in paragraph
Paragraph Triple-click in paragraph or double-click in left margin Triple-click
Entire document Triple-click in left margin or Edit → Select All Ctrl+A
Non-adjacent text Select first portion, then Ctrl+Click additional portions Ctrl+Click

Copying and Pasting Text

1

Select Text

Select the text you want to copy by dragging over it with the mouse.

2

Copy Text

Click the Copy command on the Home tab, or right-click and choose Copy, or press Ctrl+C.

3

Place Cursor

Place the cursor where you want text to appear in the document.

4

Paste Text

Click the Paste command on the Home tab, or right-click and choose Paste, or press Ctrl+V.

Finding and Replacing Text

Efficient Text Editing

When a document comprises many pages, locating specific text might be cumbersome. Word processors have mechanisms for locating specific texts and replacing them efficiently.

Finding Text

1

Open Find Dialog

Click the Home tab's Find button or press Ctrl+F to display the Find and Replace dialog box.

2

Enter Search Text

Type the text you want to find in the "Search for" textbox.

3

Start Search

Click the Find Next button. Word searches from the current cursor position to the end of the file.

4

Navigate Results

If Word finds the text, it highlights it. Click Find Next to continue searching.

Replacing Text

1

Open Replace Dialog

Click the Home tab's Replace button or press Ctrl+H to display the Find and Replace dialog box.

2

Enter Text to Find and Replace

Type the text you want to find in the "Find what" box and the replacement text in the "Replace with" box.

3

Replace Text

Click Replace to replace the next occurrence, or Replace All to replace all occurrences at once.

  4. Experiment with Replace vs Replace All functions

Spelling and Grammar Check

Proofreading Tools

When you are typing, sometimes a wavy red or green line appears beneath your text. Red wavy lines indicate spelling errors, while green wavy lines indicate grammatical errors. Word processors include proofreading tools to help correct these errors.

Using Spell Check

1

Identify Errors

Look for wavy red lines under misspelled words or wavy green lines under grammatical errors.

2

Right-Click Error

Right-click on the underlined word to see suggested corrections.

3

Select Correction

Click on the correct suggestion to replace the mistyped word automatically.

4

Use Spelling & Grammar Checker

Go to Review tab → Spelling & Grammar (or press F7) to check the entire document.

7
Activity 4.11: Text Proofreading

Instructions: Practice using spelling and grammar check tools.

  1. Open a new document and intentionally mistype several words
  2. Observe the wavy red lines that appear under misspelled words
  3. Right-click on underlined words and select correct suggestions
  4. Use the Spelling & Grammar checker (F7) to check the entire document
Important Note

A wavy red line does not always mean you have made a mistake! Proper nouns and specialist terms that Word doesn't recognize will also be underlined. You can add these to the dictionary to prevent future underlining.

Character and Paragraph Formatting

Making Documents Attractive

Formatting is the art of making your documents effective and attractive. Good formatting distinguishes different parts of your text and helps your readers take in your message. Character formatting affects individual characters, while paragraph formatting affects entire paragraphs.

Character Formatting

Changing Font
Times New Roman - Traditional serif font
Arial - Clean sans-serif font
Courier New - Monospaced font
Font Styles
Bold text for emphasis
Italic text for titles or emphasis
Underlined text for links or emphasis
Font Size
Large text for headings (18pt+)
Normal text for body (10-12pt)
Small text for footnotes (8-9pt)

Text Alignment

Align Left (Default)

Text is aligned at the left margin but jagged on the right. This is the standard alignment for most documents.

Center

Text is centred within each line, with jagged margins on both left and right. Good for titles and headings.

Align Right

Text is aligned at the right margin but jagged on the left. Often used for dates or page numbers.

Justify

Text is aligned at both the left and right margins. Word does this by adjusting the amount of space between words. Creates a clean, formal look.

Working with Objects

Enhancing Documents

In addition to text, you can add various objects to your documents including images/pictures, tables, charts, smart art, screenshots, and illustrations. These elements make documents more engaging and informative.

Inserting and Formatting Images

Cropping Images

Cropping removes part of an image to focus on a specific area. Select the image, click Format tab → Crop command, then drag the cropping handles.

Compressing Images

Reduces file size by telling Word to compress pictures. Select picture → Format tab → Compress Pictures → Choose target output.

Image Adjustments

Adjust brightness, contrast, color, and apply artistic effects. Select image → Format tab → Adjust group for various options.

Working with Tables

Tables organize information in rows and columns. Insert → Table → Choose number of rows and columns. Use Table Tools for formatting.

Activity of Integration

Real-World Application

Your class is planning an end of year party scheduled to take place on 21st November this year, in the main hall, starting at 8:30am.

INT
Integration Task: Word-process a Letter

Task: Word process a formal letter inviting the head teacher and members of staff to the end of year party.

Letter Requirements
  • Proper letter format with date, address, salutation, body, closing
  • Clear communication of purpose, time, date, venue
  • Professional appearance with appropriate formatting
  • Correct spelling and grammar
  • Appropriate font choices and sizes
  • Proper alignment and spacing
Formatting Elements to Include
  • At least 4 font features (bold, underline, font changes, size changes)
  • Appropriate alignment (left, center, right as needed)
  • Proper spacing between paragraphs
  • Bulleted or numbered list if appropriate
  • Consistent formatting throughout
Evaluation Criteria

The letter will be evaluated based on:

  • Relevance: Includes all required information (purpose, time, date, venue, addressee)
  • Accuracy: Clear purpose, correct details, proper formatting
  • Coherence: Logical flow and clarity of ideas
  • Formatting: Appropriate use of font features, alignment, spacing

Knowledge Check: Word Processing Quiz

1. Which tab in Microsoft Word contains formatting tools like bold, italic, and underline?
Correct! The Home tab contains basic formatting tools including bold, italic, underline, font selection, and font size.
Incorrect. While other tabs have important functions, the Home tab specifically contains the basic text formatting tools like bold, italic, and underline.
2. What keyboard shortcut is used to save a document?
Correct! Ctrl+S is the keyboard shortcut for saving a document. It's important to save frequently while working.
Incorrect. Ctrl+C is for copy, Ctrl+V is for paste, Ctrl+P is for print. Ctrl+S is the shortcut for saving documents.
3. Which feature allows you to change a document from portrait (vertical) to landscape (horizontal) orientation?
Correct! The Orientation command in the Page Layout tab allows you to switch between portrait and landscape page orientations.
Incorrect. While Page Setup in the File menu also contains orientation options, the direct way is using the Orientation command in the Page Layout tab.
4. What is the purpose of the "Find and Replace" feature in word processing?
Correct! Find and Replace (Ctrl+H) allows you to search for specific text in a document and replace it with different text, which is especially useful for making global changes.
Incorrect. Find and Replace specifically helps locate text and optionally replace it. Spelling/grammar check, formatting, and inserting objects are different functions.
