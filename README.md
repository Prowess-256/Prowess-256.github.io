# Personal Website — Yiga Gerald 

This folder contains a modern, minimal personal website scaffold showcasing up-to-date web practices: semantic HTML, CSS variables, Web Components, and a simple PWA service worker.

Run locally (static server). Examples:

Python 3:
```bash
python -m http.server 8000
# then open http://localhost:8000
```

Node (serve package):
```bash
npx serve . -p 8000
```

What’s included:
- `index.html` — semantic single-page layout
- `styles.css` — responsive modern CSS
- `script.js` — theme, Web Component, SW registration
- `manifest.json` & `sw.js` — PWA basics
