Pivot Tables

Pivot tables are one of Excel's most powerful features. They allow you to summarize, analyze, and explore large datasets in seconds without writing formulas.

What is a Pivot Table?

A pivot table is an interactive table that automatically extracts, organizes, and summarizes your data. You can "pivot" or rotate the data to view it from different perspectives, making it perfect for business intelligence and data analysis.

Creating a Pivot Table

  1. Select your data range - Include headers, no blank rows/columns
  2. Insert → Pivot Table - Choose location (new or existing worksheet)
  3. Drag fields to areas:
    • Rows: Categories to group by (e.g., Product, Region)
    • Columns: Additional grouping (optional)
    • Values: Numbers to summarize (e.g., Sales, Quantity)
    • Filters: Limit data shown (e.g., Year, Month)
  4. Customize - Change value field settings (Sum, Count, Average)

Advanced Lookup Functions

Lookup functions allow you to search for a value in one table and return a corresponding value from another table - essential for combining data from different sources.

VLOOKUP (Vertical Lookup)

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
  • lookup_value: The value to search for (must be in first column)
  • table_array: The table range containing the data
  • col_index_num: Which column number to return (1 = first column)
  • range_lookup: FALSE for exact match, TRUE for approximate

VLOOKUP Limitations

  • Lookup value must be in the first column of the table array
  • Only searches vertically (top to bottom)
  • Returns first match only
  • Can break if columns are inserted/deleted

XLOOKUP (Modern Replacement)

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode])

INDEX-MATCH (Flexible Alternative)

=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))
FunctionProsCons
VLOOKUPSimple, widely knownLimited to first column, breaks with column inserts
XLOOKUPFlexible, can search left/right, built-in error handlingOnly in newer Excel versions (2019+, 365)

Conditional Functions

Conditional functions allow you to perform calculations or return values based on specific criteria - essential for data analysis and reporting.

Common Conditional Functions

FunctionSyntaxPurpose
IF=IF(logical_test, value_if_true, value_if_false)Returns one value if condition is TRUE, another if FALSE
IFS=IFS(condition1, result1, condition2, result2...)Tests multiple conditions (no nested IFs needed)
SUMIF=SUMIF(range, criteria, [sum_range])Sums values based on a single condition
SUMIFS=SUMIFS(sum_range, criteria_range1, criteria1...)Sums values based on multiple conditions
COUNTIF=COUNTIF(range, criteria)Counts cells based on a single condition
COUNTIFS=COUNTIFS(criteria_range1, criteria1...)Counts cells based on multiple conditions
// Example: Grade calculation with nested IF
=IF(A1>=90, "A", IF(A1>=80, "B", IF(A1>=70, "C", IF(A1>=60, "D", "F"))))

// Example: SUMIFS for sales by region and product
=SUMIFS(SalesAmount, RegionRange, "North", ProductRange, "Electronics")

// Example: IFS (Excel 2019+)
=IFS(A1>=90, "A", A1>=80, "B", A1>=70, "C", A1>=60, "D", TRUE, "F")

Data validation controls what users can enter into cells, preventing errors and ensuring data consistency.

Types of Data Validation

Creating a Drop-Down List

  1. Select the cell(s) where you want the drop-down
  2. Data → Data Validation → Settings tab
  3. Allow: List
  4. Source: Type items separated by commas OR select a range
  5. Check "In-cell dropdown"
  6. Add Input Message and Error Alert tabs for user guidance

Macros and Automation

Macros are recorded sequences of actions that can be played back to automate repetitive tasks. They use VBA (Visual Basic for Applications) code.

Getting Started with Macros

  1. Enable Developer Tab: File → Options → Customize Ribbon → Check "Developer"
  2. Record a Macro: Developer → Record Macro → Name it → Perform actions → Stop Recording
  3. Run a Macro: Developer → Macros → Select macro → Run
  4. Assign to Button: Insert Form Control button → Assign macro

Macro Security Warning

Macros can contain harmful code. Only enable macros from trusted sources. Always save macro-enabled workbooks as .xlsm (not .xlsx).

Common Macro Use Cases

  • Formatting reports - Apply consistent formatting to monthly reports
  • Data cleaning - Remove duplicates, trim spaces, fix formatting
  • Exporting data - Save specific sheets or ranges as PDF/CSV
  • Email automation - Generate and send emails from Excel data
  • Dashboard refresh - Update all pivot tables and charts with one click

Creating Interactive Dashboards

A dashboard is a visual display of key metrics and data points, allowing users to monitor performance at a glance.

Dashboard Design Principles

  • Keep it simple - Focus on key metrics, avoid clutter
  • Use consistent colors - Brand colors, color-coded categories
  • Add interactivity - Slicers, timelines, drop-downs
  • Make it readable - Clear labels, appropriate font sizes
  • Update automatically - Use pivot tables and dynamic ranges

Dashboard Components

  • KPI Cards - Large numbers showing key metrics (Total Sales, Profit Margin)
  • Charts - Bar, line, pie charts for trends and comparisons
  • Slicers - Interactive filters for pivot tables/charts
  • Timeline - Date-based filter control
  • Sparklines - Mini charts inside cells showing trends
  • Conditional Formatting - Color-coded data bars, icon sets

What-If Analysis

What-If analysis tools help you explore how changing input values affects outcomes - essential for budgeting, forecasting, and decision-making.

Goal Seek

// Find the input needed to achieve a desired result
Data → What-If Analysis → Goal Seek
Set cell: (formula cell) → To value: (desired result) → By changing cell: (input cell)

Data Tables

// See how changing 1-2 variables affects results
Data → What-If Analysis → Data Table
Row input cell: (variable 1) → Column input cell: (variable 2)

Scenario Manager

// Compare multiple scenarios (Best Case, Worst Case, Most Likely)
Data → What-If Analysis → Scenario Manager → Add scenarios → Show results
