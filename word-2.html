Styles and Formatting

Styles are one of the most powerful features in word processors. They ensure consistent formatting throughout your document and make global changes easy.

What are Styles?

A style is a set of formatting attributes (font, size, color, spacing, etc.) saved under a name. When you apply a style, all selected text receives those attributes. Changing the style updates all text using that style.

Types of Styles

Creating and Modifying Styles

  1. Create a new style: Home tab → Styles group → Create a Style (or use Alt+Ctrl+Shift+S)
  2. Modify a style: Right-click a style in the Styles gallery → Modify → Change formatting → OK
  3. Update style to match selection: Select text with desired formatting → Right-click style → Update [Style Name] to Match Selection
  4. Apply a style: Select text → Click style name in Styles gallery

Templates

Templates are pre-designed documents that save time and ensure consistency across similar documents like letters, reports, invoices, and newsletters.

What is a Template?

A template is a document with predefined settings, styles, and content that serves as a starting point for new documents. Templates can contain boilerplate text, logos, headers, footers, and styles.

Mail Merge

Mail merge allows you to create personalized letters, emails, labels, or envelopes for multiple recipients using a data source.

Mail Merge Components

  • Main Document: The template with placeholders (merge fields)
  • Data Source: The list of recipient information (Excel spreadsheet, Outlook contacts, Access database)
  • Merged Document: The final personalized documents

Mail Merge Process

  1. Prepare Data Source: Create an Excel file with column headers (Name, Address, City, etc.)
  2. Create Main Document: Write your letter or email with placeholders
  3. Start Mail Merge: Mailings tab → Start Mail Merge → Letters (or Email Messages)
  4. Select Recipients: Use an existing list → Browse → Select your Excel file
  5. Insert Merge Fields: Place cursor → Insert Merge Field → Choose field (e.g., «Name», «Address»)
  6. Preview Results: Check that data appears correctly
  7. Complete Merge: Finish & Merge → Print Documents or Send Email Messages

Table of Contents and References

Professional documents often require automatic tables of contents, indexes, citations, and cross-references.

Creating a Table of Contents (TOC)

  1. Apply Heading Styles (Heading 1, Heading 2, Heading 3) to your headings
  2. Place cursor where you want the TOC (usually after title page)
  3. References tab → Table of Contents → Choose a style
  4. TOC is automatically generated based on heading levels
  5. Update TOC: Click anywhere in TOC → Update Table → Update entire table

Adding Captions and Cross-References

  1. Add caption: Right-click image/table → Insert Caption → Choose label (Figure/Table)
  2. Cross-reference: References tab → Cross-reference → Reference type (Figure/Table) → Insert
  3. Update fields: Select all (Ctrl+A) → F9 to update cross-references

Collaboration Tools

Modern word processors include powerful collaboration features that allow multiple people to work on the same document.

Track Changes Example

Track Changes

  1. Turn on Track Changes: Review tab → Track Changes (Ctrl+Shift+E)
  2. Edits appear in different colors for each reviewer
  3. Accept/Reject Changes: Review tab → Accept or Reject buttons
  4. Change user name: Review tab → Track Changes dropdown → Change User Name

Comments

  1. Add comment: Select text → Review tab → New Comment (Ctrl+Alt+M)
  2. Reply to comment: Click Reply button below comment
  3. Resolve comment: Click Resolve button when issue is addressed
  4. Delete comment: Right-click comment → Delete Comment

Macros and Automation

What are Macros?

Macros are recorded sequences of commands that automate repetitive tasks. They use VBA (Visual Basic for Applications) code and can save hours of manual work.

Recording a Macro

  1. Enable Developer Tab: File → Options → Customize Ribbon → Check "Developer"
  2. Record Macro: Developer tab → Record Macro
  3. Name your macro: No spaces, start with letter (e.g., FormatReport)
  4. Assign shortcut key (optional): Ctrl + Shift + (letter)
  5. Store macro in: Normal.dotm (all documents) or Current Document
  6. Perform actions: Formatting, inserting, deleting, etc.
  7. Stop Recording: Developer tab → Stop Recording
  8. Run Macro: Developer tab → Macros → Select macro → Run

Macro Security

Important Security Notes

  • Macros can contain harmful code (viruses)
  • Only enable macros from trusted sources
  • Save macro-enabled documents as .docm (not .docx)
  • Change macro settings: File → Options → Trust Center → Trust Center Settings → Macro Settings
  • Recommended setting: "Disable all macros with notification"

Common Macro Examples

  • Format Report: Apply headers, footers, margins, font styles
  • Insert Company Signature: Add closing and signature block
  • Clean Up Text: Remove extra spaces, fix capitalization
  • Export as PDF: Automatically save document as PDF
  • Batch Processing: Apply same formatting to multiple documents
