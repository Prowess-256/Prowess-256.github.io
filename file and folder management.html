Files and Folders

Understanding Files and Folders

Files can be stored in folders. Folders can be stored within other folders and these are referred to as sub-folders. File names are made up of two parts: the document name and file extension.

File Extensions

The document name can be up to 256 characters long, including spaces while the file extension is determined by the application being used. Some examples of file extensions are shown below:

Microsoft Word

Word processing documents

.doc / .docx

Microsoft PowerPoint

Presentation files

.ppt / .pptx

Microsoft Excel

Spreadsheet files

.xls / .xlsx

PDF Document

Portable Document Format

.pdf

Storage Media

Types of Storage Media

Files and folders can be stored on various storage media. Different storage media have different characteristics in terms of capacity, speed, portability, and durability.

Common Storage Media

CDs and DVDs

Optical storage media. CDs typically store 700MB, DVDs store 4.7GB or more. Good for backups and distribution but slower than hard drives.

Flash Drives

Portable, rewritable storage. Capacities from 1GB to 1TB+. Fast, durable, and convenient for transferring files between computers.

Memory Cards

Used in cameras, phones, and other portable devices. Various formats (SD, microSD). Portable but can be easily lost.

Hard Disk Drives

Internal storage in computers. High capacity (500GB to 10TB+). Fast but not portable (unless external). Sensitive to physical shock.

Comparison of Storage Media

Storage Media Capacity Range Advantages Disadvantages
Hard Disk Drive (HDD) 500GB - 10TB+ High capacity, cost-effective, fast access Not portable, sensitive to shock, moving parts
Solid State Drive (SSD) 120GB - 4TB Very fast, durable, no moving parts More expensive per GB, limited write cycles
Flash Drive 1GB - 1TB+ Portable, durable, widely compatible Can be easily lost, smaller capacity than HDDs
CD/DVD 700MB - 17GB Inexpensive, good for distribution Slow, limited capacity, can scratch easily

Organizing Files

Importance of Organization

The management of computer files and paper files has much in common. If all paper documents were stored in a single drawer without using folders, it would soon become impossible to find anything. A well-organized house will have some filing system to segregate electric bills from telephone bills and from bank statements. Files on a computer should be managed in a similar manner.

Creating an Organized Folder Structure

A good practice is to use a Personal Folder to organize your files. This is the equivalent of a filing cabinet in paper filing. It can be created in the My Documents folder or in the C: Drive of the computer. This folder is the Root Folder of the filing system.

Managing Files and Folders

File Operations

Files and folders can be selected, copied, pasted, moved, renamed and deleted. These operations help you manage your digital files effectively.

Selecting Files

1

Select Single File

Just click the file. It changes color on selection.

2

Select Consecutive Files

Click the first file, hold down the Shift key and select the last file. The files in between are automatically selected.

3

Select Non-Consecutive Files

Hold down the Ctrl key (Cmd key on Mac) and select the files in turn.

4

Select All Files

Click the Edit command and choose Select All, or press Ctrl+A.

Copying and Pasting Files

1

Copy Files

Select the required file(s). Then right-click the files and choose Copy, or press Ctrl+C. The files are copied to the Clipboard.

2

Paste Files

Browse to the destination folder, right-click it and choose Paste, or press Ctrl+V.

Moving, Renaming, and Deleting Files

Operation Method Keyboard Shortcut
Moving Files Select files → Right-click → Cut → Navigate to destination → Right-click → Paste Ctrl+X (Cut), Ctrl+V (Paste)
Renaming Files Right-click file → Choose Rename → Type new name → Press Enter Select file → F2 → Type new name → Enter
Deleting Files Select files → Right-click → Choose Delete → Click Yes in dialog box Select files → Delete key → Click Yes

The Recycle Bin

Understanding the Recycle Bin

Files and folders deleted from the computer are placed in the Recycle Bin (Windows) or Trash (Mac). They are not permanently lost until the Recycle Bin is emptied. This provides a safety net in case you accidentally delete important files.

Managing the Recycle Bin

1

Delete a File/Folder

Right-click the folder/file and select Delete, or select and press Delete key. The item goes to Recycle Bin.

2

Check Recycle Bin

Open Recycle Bin from desktop to confirm if deleted items have arrived there.

3

Restore Deleted Items

Right-click Recycle Bin and choose Open. Select item(s) to restore, then from the File menu choose Restore, or right-click and select Restore.

4

Empty Recycle Bin

Right-click Recycle Bin and choose Empty Recycle Bin to permanently delete all items. This action cannot be undone!

Measurement of Storage Capacity

Data Storage Units

In a computer system, data is represented using the binary system; combinations of binary digits (bits). There are only two binary digits, 1 and 0. Data storage has various units including bits (b), Bytes (B), Kilobytes (KB), Megabytes (MB), Gigabytes (GB), and Terabytes (TB).

Understanding Data Units

Bit (b) The smallest unit of data (0 or 1)
Byte (B) 8 bits = 1 byte (can represent one character)
Kilobyte (KB) 1,024 bytes (2¹⁰ bytes)
Megabyte (MB) 1,024 KB = 1,048,576 bytes
Gigabyte (GB) 1,024 MB = 1,073,741,824 bytes
Terabyte (TB) 1,024 GB = 1,099,511,627,776 bytes

Conversion Between Units

From To Multiply By Example
Bytes Kilobytes ÷ 1,024 2,048 bytes = 2 KB
Kilobytes Megabytes ÷ 1,024 2,048 KB = 2 MB
Megabytes Gigabytes ÷ 1,024 2,048 MB = 2 GB
Gigabytes Terabytes ÷ 1,024 2,048 GB = 2 TB

Important Note

Many hard drive manufacturers use a decimal number system to define amounts of storage space. As a result, 1 MB is defined as one million bytes, 1 GB is defined as one billion bytes, and so on. Since your computer uses a binary system, you may notice a discrepancy between your hard drive's published capacity and the capacity acknowledged by your computer.

Activity of Integration

Real-World Scenario

These integration activities test your ability to apply file and folder management concepts to practical situations.

INT
Integration Task 1

Scenario: A researcher saved her draft work on a CD ROM from a friend's computer with an intention of sending it to her supervisor by e-mail once she got home. However, on reaching home, she realized that her computer could not read a CD ROM.

Task: How can you advise this researcher to have her work sent to the supervisor without physically going back to her friend?

Possible Solutions
  • Use a computer with a CD drive at school, cyber cafe, or library to read the CD
  • Copy files from CD to a flash drive or upload to cloud storage (Google Drive, Dropbox)
  • Email the files from the location with CD access
  • Use network sharing if both computers are on the same network
INT
Integration Task 2

Scenario: A student borrowed a computer with a hard disk of 40GB on which he saved his project work for 3 years. The project work on the hard disk is stored on a space of 30GB. Recently, the owner of the computer requested to have it back and provided the student with a pack of 100 CDs each with a storage capacity of 700MB on which project data can be transferred.

Tasks:

  1. Describe how the project data could be transferred from the hard disk onto the CDs provided by the student
  2. How many CDs full of data do you think the student used? Give reasons for your answer
Calculations and Solutions
  • Transfer method: Use CD burning software, organize files into CD-sized chunks, burn sequentially
  • Number of CDs: 30GB = 30,720MB. 30,720MB ÷ 700MB ≈ 44 CDs (rounded up because partial CDs are needed)
  • The student would need approximately 44 CDs to transfer 30GB of data at 700MB per CD

Knowledge Check: File Management Quiz

1. What is the file extension for Microsoft Word documents?
Correct! Microsoft Word documents use .doc (older versions) or .docx (newer versions) file extensions.
Incorrect. .txt is for plain text files, .pdf is for Portable Document Format, .xls is for Excel spreadsheets. Word documents use .doc or .docx.
2. How many bytes are in a kilobyte (KB)?
Correct! A kilobyte (KB) is 1,024 bytes because computers use binary (base two) math.
Incorrect. While sometimes approximated as 1,000 bytes in marketing, technically a kilobyte is 1,024 bytes (2¹⁰ bytes) in binary systems.
3. What happens to files when you delete them in Windows?
Correct! When you delete files in Windows, they go to the Recycle Bin where they remain until you empty the bin, giving you a chance to restore them if deleted accidentally.
Incorrect. Files deleted in Windows go to the Recycle Bin first, not immediately erased. You must empty the Recycle Bin to permanently delete them.
4. Which key combination is used to select multiple non-consecutive files?
Correct! Ctrl + Click (Cmd + Click on Mac) is used to select multiple non-consecutive files.
Incorrect. Shift + Click selects consecutive files, while Ctrl + Click (Cmd + Click on Mac) selects non-consecutive files.
