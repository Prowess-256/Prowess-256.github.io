What is Computer Hardware?

A computer is a system of many parts working together. The tangible parts that you can touch and feel such as the monitor, keyboard, mouse, disk drives, printer, scanner and speakers are collectively referred to as hardware. The opposite of hardware is software, which refers to the instructions or programs that tell the hardware what to do.

Hardware vs Software

In comparison with the human being, hardware may be considered as the body while software is the brain. Both are essential for a computer to function.

Soft Copy vs Hard Copy

  • Soft Copy: Information displayed on a screen or stored electronically (e.g., document on screen, PDF file)
  • Hard Copy: Physical printed version of information (e.g., printed document, photograph)

Internal Components of a Computer

CPU (Central Processing Unit)

The "brain" of the computer - processes all instructions

RAM (Random Access Memory)

Temporary memory - stores data while computer is running

Hard Drive / SSD

Permanent storage for files and programs

Motherboard

The main circuit board - connects all components

Power Supply Unit (PSU)

Converts electricity to power all components

Cooling Fan

Prevents overheating of components

How Components Work Together

  1. Input → Keyboard/Mouse sends data
  2. Processing → CPU processes the data using RAM
  3. Storage → Hard drive saves data permanently
  4. Output → Monitor displays the result

Assembling a Computer System

Why Proper Assembly Matters

When hardware devices are connected properly, they make a fully functional computer system. Improper connections can damage components or prevent the system from working.

Steps for Assembling a Desktop Computer

1

Check Available Devices

Verify all required devices are present: system unit, monitor, keyboard, mouse, power cables, and any other peripherals.

2

Connect Monitor Cable

Locate the monitor cable (VGA, HDMI, or DisplayPort). Connect one end to the monitor port on the back of the computer case and the other end to the monitor. Hand-tighten any screws.

3

Connect Input Devices

Connect keyboard and mouse to USB ports. Match the shapes and colors of connectors to the correct ports.

4

Connect Power Supply Cables

Plug the first power supply cable into the back of the computer case, then into a surge protector. Connect the monitor to the surge protector.

5

Connect to Power Source

Finally, plug the surge protector into a wall outlet. Turn the surge protector on if it has a power switch.

Safety Precautions During Assembly

  • Handle components with care to avoid static electricity damage (use an anti-static wrist strap)
  • Ensure power is disconnected before connecting/disconnecting cables
  • Match connectors carefully - don't force connections
  • Work on a clean, dry, non-carpeted surface
  • Keep screws and small parts organized

Starting and Shutting Down a Computer

What is Booting?

The process of starting a computer is called booting. After assembling a computer, the next step is to power it on correctly, use it, and then shut it down with proper procedures.

Starting the Computer (Boot Process)

  1. Make sure all plugs are well connected
  2. Switch on the electricity socket and the UPS (if available)
  3. Press the power button on the computer monitor first - it should show signal
  4. Press the power button on the system unit
  5. The computer will run POST (Power-On Self Test) to check components
  6. The operating system (Windows, Linux, macOS) will load
  7. If a password is required, enter it at the login screen
  8. The Desktop will appear - give it time to load startup programs

Shutting Down a Computer Properly

Turn Off Computer

Start → Power → Shut Down. Closes all programs and turns off the computer safely.

Log Off

Closes your user session but leaves the computer running for another user.

Switch User

Allows another user to log in without closing your programs.

Why Proper Shutdown Matters

  • Prevents data loss or corruption
  • Allows programs to save settings properly
  • Prevents damage to the hard drive
  • Ensures Windows updates install correctly
  • Extends the life of hardware components

Laptop Computers

Laptop vs Desktop Differences

  • Portability: Laptops are designed to be carried and used anywhere
  • Battery: Laptops have built-in batteries for cordless operation
  • Integrated Components: Keyboard, touchpad, screen, and speakers are built-in
  • Upgradability: Desktops are easier to upgrade than laptops

Setting Up a Laptop

  1. Open the laptop lid
  2. If the battery has charge, press the power button
  3. If the battery is low, connect the AC adapter (charger)
  4. Follow the on-screen setup instructions (for first-time setup)
  5. Connect to Wi-Fi network
  6. Create or sign in to user account

Component Quick Guide

  • CPU: Processes instructions
  • RAM: Temporary memory (volatile)
  • HDD/SSD: Permanent storage
  • Motherboard: Connects all components
  • PSU: Powers the system
  • GPU: Handles graphics (optional on some systems)

Troubleshooting Tips

  • No power? Check power cable and wall outlet
  • No display? Check monitor cable and input source
  • Keyboard not working? Try different USB port
  • Slow computer? Check RAM usage, close programs
  • Overheating? Clean fans, ensure ventilation
