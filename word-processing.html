Features of a Word Processor

What is Word Processing?

Word processing is a very important skill for computer literacy. Once you learn word processing, you will be in position to use word processing software (e.g., MS Word) appropriately to create, edit and print documents. Microsoft Office Word is one of the most commonly used word processing software.

Word Processor Interface

A word processor has numerous features whose uses you need to understand. The table below shows a typical word processor window with key features:

Feature Tab/Location Function
Office Button/File Menu Top-left corner Access to Save, Open, Print, and other file operations
Home Tab Ribbon (top) Basic formatting tools: font, paragraph, styles, editing
Insert Tab Ribbon (top) Insert pages, tables, illustrations, links, headers/footers
Page Layout Tab Ribbon (top) Page setup, themes, page background, paragraph spacing
References Tab Ribbon (top) Table of contents, footnotes, citations, bibliography
Mailings Tab Ribbon (top) Mail merge, envelopes, labels for bulk mailing
Review Tab Ribbon (top) Spelling & grammar, proofing, comments, tracking changes
View Tab Ribbon (top) Document views, zoom, window arrangements, macros

Activity: Understanding Word Processor Features

Instructions: In groups, explore the word processor interface and identify features.

  1. Open a word processor (Start → All Programs → MS Office → Word)
  2. Identify the groups of word processing features on different tabs
  3. Type the sentence "I love my school"
  4. Select (highlight) the sentence and click on any three features
  5. Observe the changes which occur in the text
  6. State the function of each of the features identified

Customizing Word Processing Environment

Setting Up Your Workspace

Before you begin creating documents, ensure that you have set up your Word environment and become familiar with key tasks such as minimizing and maximizing the Ribbon, configuring the Quick Access toolbar, using the ruler, word counting and zooming tools.

Customizing the Quick Access Toolbar

Step 1: Click the arrow to the right of the Quick Access toolbar (top-left corner of Word window).
Step 2: Select the command you want to add from the drop-down list. It will appear in the Quick Access toolbar.
Step 3: Right-click anywhere in the main menu and select "Minimize the Ribbon" to toggle the Ribbon on and off.
Step 4: Right-click anywhere on the taskbar and select the items you would like to appear on your taskbar.

Saving Documents

Importance of Saving

Saving is a process of storing a document in a certain location or creating a file. This can be done on a newly created document or on an already existing document. Saving is normally in two categories: Save and Save As.

Operation When to Use Keyboard Shortcut
Save First time saving or updating existing file Ctrl + S
Save As Creating copy, changing location, or changing file type F12

Working with Text

Basic Text Operations

Working with text involves selecting, inserting, deleting, copying, and pasting text. These fundamental skills are essential for creating and editing documents effectively.

Text Selection Methods

To Select Method Keyboard Shortcut
Single word Double-click the word Double-click
Line of text Click in left margin next to line -
Paragraph Triple-click in paragraph or double-click in left margin Triple-click
Entire document Triple-click in left margin or Edit → Select All Ctrl + A
Non-adjacent text Select first portion, then Ctrl + Click additional portions Ctrl + Click

Activity: Working with Text

Instructions: Practice basic text operations in a document.

  1. Type some text in your text area (about four paragraphs)
  2. Practice selecting text using different methods
  3. Insert text anywhere in your document by clicking and typing
  4. Delete text using Backspace (left of cursor) and Delete (right of cursor) keys

Page Layout

Document Layout Settings

Page layout involves changing default settings to suit your document requirements. You can change margins, document orientation, use columns in your document, and adjust line spacing of text.

Page Orientation

  • Portrait: Vertical orientation (taller than wide) - default for most documents
  • Landscape: Horizontal orientation (wider than tall) - good for tables, charts, wide images

Setting Margins

  • Normal: 1 inch on all sides (default)
  • Narrow: 0.5 inch on all sides (more content per page)
  • Moderate: 0.75 inch on sides, 1 inch top/bottom
  • Wide: 1 inch sides, 2 inches top/bottom
  • Mirrored: For book-style printing (inside/outside margins different)

Finding and Replacing Text

Efficient Text Editing

When a document comprises many pages, locating specific text might be cumbersome. Word processors have mechanisms for locating specific texts and replacing them efficiently.

Operation Keyboard Shortcut Description
Find Ctrl + F Opens Navigation pane to search for text
Replace Ctrl + H Find text and replace it with different text
Go To Ctrl + G Jump to specific page, section, or line

Spelling and Grammar Check

Proofreading Tools

When you are typing, sometimes a wavy red or green line appears beneath your text. Red wavy lines indicate spelling errors, while green wavy lines indicate grammatical errors.

3
Activity: Text Proofreading

Instructions: Practice using spelling and grammar check tools.

  1. Open a new document and intentionally mistype several words
  2. Observe the wavy red lines that appear under misspelled words
  3. Right-click on underlined words and select correct suggestions
  4. Use the Spelling & Grammar checker (F7) to check the entire document

Character and Paragraph Formatting

Making Documents Attractive

Formatting is the art of making your documents effective and attractive. Good formatting distinguishes different parts of your text and helps your readers take in your message.

Character Formatting Examples

Bold text for emphasis

Italic text for titles or foreign words

Underlined text for links or special emphasis

Larger text for headings

Colored text for highlighting

Text Alignment

Align Left: Text is aligned at the left margin (default)
Center: Text is centered within the page
Align Right: Text is aligned at the right margin
Justify: Text is aligned at both left and right margins
