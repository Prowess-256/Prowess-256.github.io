Introduction to Web Design

Web design is the process of creating websites. It encompasses several different aspects, including webpage layout, content production, and graphic design. While web design and web development are often used interchangeably, web design is technically a subset of the broader category of web development.

The Three Pillars of Web Design

  • HTML (HyperText Markup Language): The structure and content of a webpage
  • CSS (Cascading Style Sheets): The visual appearance and layout
  • JavaScript: Interactivity and dynamic behavior

HTML Basics

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of a webpage using elements represented by tags.

Basic HTML Structure

<!-- This is a comment -->
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Page Title</title>
</head>
<body>
    <h1>Main Heading</h1>
    <p>This is a paragraph of text.</p>
    <a href="https://example.com">Click here</a>
</body>
</html>

Layout and Flexbox

Creating complex layouts is one of the most important aspects of web design. CSS Flexbox makes it easy to create flexible, responsive layouts without using complex floats or positioning.

Flexbox Properties

/* Container properties */
.container {
    display: flex;
    flex-direction: row | column;
    justify-content: center | space-between | flex-start | flex-end;
    align-items: center | stretch | flex-start | flex-end;
    gap: 20px;
}

/* Child properties */
.item {
    flex: 1;
}

Responsive Design

What is Responsive Design?

Responsive design ensures that websites look good and function properly on all devices - desktops, tablets, and mobile phones. It uses flexible layouts, flexible images, and CSS media queries.

Media Queries

/* Mobile styles (default) */
.container { display: block; }

/* Tablet styles (768px and up) */
@media (min-width: 768px) {
    .container { display: flex; }
}

/* Desktop styles (1024px and up) */
@media (min-width: 1024px) {
    .container { max-width: 1200px; }
}

Responsive Design Principles

  • Mobile First: Design for mobile screens first, then scale up
  • Fluid Images: Use max-width: 100% to prevent images from overflowing
  • Relative Units: Use rem, em, vw, vh instead of fixed pixels
  • Flexible Grids: Use Flexbox or CSS Grid for flexible layouts
  • Touch-Friendly: Make buttons and links large enough for touch (min 44x44px)
5
Activity: Make Your Page Responsive

Objective: Add media queries to make your webpage responsive.

  1. Add a meta viewport tag to your HTML: <meta name="viewport" content="width=device-width, initial-scale=1">
  2. Use relative units (%, rem, vw) instead of fixed pixels where possible
  3. Add a media query for tablets (min-width: 768px) that changes your layout
  4. Add a media query for desktops (min-width: 1024px) that sets a max-width container
  5. Test your page by resizing your browser window
  6. Use Chrome DevTools Device Toolbar to test on different devices

Wireframing and Planning

Before writing code, professional web designers create wireframes - simple sketches of the website layout that focus on structure, not visual details.
