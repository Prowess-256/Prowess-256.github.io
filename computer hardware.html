Meaning of Computer Hardware

What is Computer Hardware?

A computer is a system of many parts working together. The tangible parts that you can touch and feel such as the monitor, keyboard, mouse, disk drives, printer, scanner and speakers are collectively referred to as hardware. The opposite of hardware is software, which refers to the instructions or programs that tell the hardware what to do.

Categories of Computer Hardware

Hardware devices are categorized according to their functions. The various hardware categories include:

Input Devices

Used for entering data or information into the computer. Examples: keyboard, mouse, microphone, scanner, camera.

Output Devices

Used for producing or displaying information which can be in form of a soft copy or hard copy. Examples: monitor, printer, speakers, projector.

Storage Devices

Used for storing data or information for future use. Can be internal (hard disk) or external (flash drive, CD).

Processing Devices

Process data and instructions. The Central Processing Unit (CPU) is the main processing device.

Communication Devices

Enable computers to connect and communicate with other devices. Examples: modem, network card, router.

Soft Copy vs Hard Copy

Soft Copy: Information displayed on a screen or stored electronically (e.g., document on computer screen, PDF file).

Hard Copy: Physical printed version of information (e.g., printed document, photograph).

Assembling a Computer System

Computer System Assembly

When hardware devices are connected together properly, they make a computer system. For a computer system to work well, hardware devices must be connected properly. If you are setting up a newly purchased computer, you will probably find a how-to use or a user guide in the packaging that includes step-by-step details.

Steps for Assembling a Desktop Computer

1

Check Available Devices

Check whether all the required devices are available: system unit, monitor, keyboard, mouse, power cables, and any other peripherals.

2

Connect Monitor Cable

Locate the monitor cable (usually VGA or DVI). VGA cables often have blue connectors. Connect one end to the monitor port on the back of the computer case and the other end to the monitor. Hand-tighten the plastic-covered screws to secure it.

3

Connect Other Devices

Connect other devices by looking at the port types: USB for keyboard and mouse, audio ports for speakers/microphone, etc. Match the shapes and colors of connectors to the correct ports.

4

Connect Power Supply Cables

Locate the power supply cables. Plug the first power supply cable into the back of the computer case, and then into a surge protector. Then, using the other cable, connect the monitor to the surge protector.

5

Connect to Power Source

Finally, plug the surge protector into a wall outlet. You may also need to turn the surge protector on if it has a power switch.

Important Note

If you don't have a surge protector, you can plug the computer directly into the wall. However, this is not recommended, as electrical surges can damage your computer.

  • Work on a clean, dry surface

Starting and Shutting Down a Computer System

Booting Process

The process of starting a computer is called booting. After assembling a computer, the next step is to power it on correctly, use it, and then shut it down with proper procedures.

Starting the Computer

  1. Make sure all the plugs are well connected
  2. Switch on the electricity socket and the Uninterruptible Power Supply Unit (if available)
  3. Press the power button on the computer monitor first - it should show signal
  4. Press the power button on the system unit
  5. The computer should now start to boot and load the operating system (e.g., Windows)
  6. If the welcome screen appears, select your username and enter the password
  7. The Desktop should now appear
  8. Give it time to load the elements and start up programs

Shutting Down a Computer System

Proper shutdown is important to prevent data loss and hardware damage:

Turn Off Computer

Located on the Start menu. The Turn Off Computer dialog has options to turn off, standby/hibernate, or restart the computer.

Log Off

Log Off option is also located on the Start menu. This closes your user session but leaves the computer running.

Switch User

Allows another user to log in without closing your programs. Also located on the Start menu.

Setting Up a Laptop Computer

Laptop Computer Setup

If you have a laptop, setup should be very easy. Just open it up and press the power button. If the battery is not charged, you will need to plug in the AC adapter and charge it before using it.

Battery

Check battery charge level before use

AC Adapter

Power Button

Peripherals

Knowledge Check: Computer Hardware Quiz

1. What is the process of starting a computer called?
Correct! The process of starting a computer is called booting.
Incorrect. The correct term is "booting" - the process a computer goes through when starting up.
2. Which of these is an INPUT device?
Correct! The keyboard is an input device - it allows you to enter data into the computer.
Incorrect. Monitor, printer, and speakers are all output devices. The keyboard is an input device.
3. What should you connect a computer to for protection against electrical surges?
Correct! A surge protector protects computer equipment from voltage spikes that can damage components.
Incorrect. While you can plug directly into a wall outlet, a surge protector is recommended to protect against electrical surges that can damage your computer.
4. Which component is considered the "brain" of the computer?
Correct! The CPU (Central Processing Unit) is often called the "brain" of the computer because it processes instructions and performs calculations.
Incorrect. While all are important components, the CPU (Central Processing Unit) is specifically referred to as the "brain" of the computer.
